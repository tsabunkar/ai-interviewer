# API Documentation

This directory contains the OpenAPI (Swagger) documentation for the Arch2Lead Interviewer backend services.

## Local Development Server

For local testing, a simple HTTP server is provided to simulate the API endpoints.

### Starting the Server

To start the local development server:

```bash
# Using the script
./scripts/start-server.sh

# Or directly
go run cmd/server/main.go
```

The server will start on port 8080 by default (http://localhost:8080).

### Available Endpoints

- `GET /question` - Fetch daily coding question
- `POST /answer` - Submit coding answer
- `GET /results` - Get evaluation results
- `GET /leaderboard` - Get leaderboard rankings
- `GET /stats` - Get user statistics
- `POST /generate-question` - Generate new question

### Testing the Endpoints

You can test the endpoints using curl:

```bash
# Fetch question
curl http://localhost:8080/question

# Submit answer
curl -X POST http://localhost:8080/answer \
  -H "Content-Type: application/json" \
  -d '{"userId": "user123", "questionDate": "2026-06-22", "answer": "function solution() { return true; }"}'

# Get results
curl http://localhost:8080/results
```

Note: The local server provides mock responses for testing purposes. For production, the services run as AWS Lambda functions.

## Files

- `swagger.yaml` - The main OpenAPI specification in YAML format
- `swagger.json` - The main OpenAPI specification in JSON format (generated by running the script)

## Generating Swagger Documentation

To generate or update the Swagger JSON documentation:

1. Make sure you have the required dependencies:

   ```bash
   make tidy
   ```

2. Run the generation script using either method:

   ```bash
   # Using make (recommended)
   make docs

   # Or directly running the script
   go run scripts/generate-swagger.go
   ```

This will create or update the `swagger.json` file with the latest API specifications.

## Viewing the Documentation

You can view the documentation using any OpenAPI/Swagger viewer:

1. Online viewers:
   - https://editor.swagger.io/
   - https://petstore.swagger.io/

2. Local viewer:
   - Install Swagger UI locally
   - Or use a VS Code extension like "Swagger Viewer"

Simply upload or open the `swagger.yaml` or `swagger.json` file in any of these tools to view the interactive API documentation.

## Keeping Documentation in Sync

When modifying the Lambda functions, remember to update the corresponding sections in the Swagger specification to keep the documentation accurate and up-to-date.
